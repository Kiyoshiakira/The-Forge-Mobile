User Flow:
  1. Tap FAB (+) on Project List Screen
  2. Wizard slides up from bottom
  3. Select project type → Next
  4. Enter title, pitch, cover → Next
  5. Select template, toggle features, invite → Create
  6. Project appears in list with all settings applied

Data Flow:
  NewProjectData {
    type: ProjectType.Story
    title: "My Awesome Project"
    pitch: "A brief description..."
    coverUri: Uri?
    template: ProjectTemplate.Blank
    enableAuditions: true
    enableAI: false
    invitees: ["alice@example.com"]
  }
  ↓
  Project(
    name = data.title,
    owner = currentUser,
    bannerUri = data.coverUri,
    collaborators = [currentUser, ...invitees],
    tools = [defaultTool]
  )
